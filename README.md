# 泊序 · 智慧停车管理前端

基于 Vue 3、TypeScript、Vite、Element Plus、Pinia 的停车管理前端 MVP。抓拍图片可经本地 Node 代理调用腾讯云车牌识别；停车会话、计费、支付和通行状态仍为本地演示流程。

## 运行

```bash
npm install
npm run dev
```

打开 <http://127.0.0.1:5173>。`npm run dev` 同时启动前端和 OCR 代理；请只运行一套开发服务。若 3001 或 5173 端口已被占用，新启动会直接提示并退出，不再自动切换到 5174。此时使用已有的 5173 页面，或先结束旧的 `npm run dev` 再启动。生产构建运行 `npm run build`，测试运行 `npm test`。

## 最小验收流程

1. 打开“出入口值守”，上传 JPG/PNG 抓拍图并点击“接口识别”。如图片包含多个车牌，选择当前车道的车辆；核对车牌后，选择入口编号并点击“确认车辆入场”。未填写密钥时仍可点击“模拟识别”或手动输入车牌验证页面流程。
2. 在出口上传抓拍图并点击“接口识别”，选择与入场记录相同的车牌；选择出口编号，点击“匹配出场并计费”。也可点击“模拟识别”快速填入最近一辆在场车。
3. 页面展示入场时间、出场时间、停车时长、应付金额、支付状态，以及可复制的 JSON。
4. 若金额大于零，打开“收费工作台”，点击“演示确认支付”；随后点击“确认车辆通过”。零元车辆直接确认通过。
5. 在“在场车辆”“进出记录”查看同步结果。重复入场或未找到入场记录可在“异常处理”查看。

演示数据保存在当前浏览器会话的 `sessionStorage` 中，关闭浏览器会话后消失。页面底部可重置示例数据。示例费率是免费 15 分钟、每不足一小时按一小时收取 5 元、每 24 小时封顶 40 元，可在“收费规则”修改。正式费率需要项目方确认，正式报价应由后端计算。

## 腾讯云车牌识别配置

项目根目录已创建 `.env`。请只在其中填写从腾讯云 API 密钥管理获取的 **SecretId** 和 **SecretKey**：

```dotenv
TENCENTCLOUD_SECRET_ID=在这里填写你的SecretId
TENCENTCLOUD_SECRET_KEY=在这里填写你的SecretKey
```

**不要填账号登录密码，也不要使用 `VITE_` 前缀保存密钥。** `.env` 已加入 `.gitignore`。新版 `npm run dev` 会在 `.env` 保存后自动重启 OCR 代理，并在终端显示密钥是否已加载（不会输出密钥内容）。若开发服务早于此改动启动，请先完整结束旧服务，再运行 `npm run dev`。前端向同源 `/api/recognitions` 上传图片，Vite 转发至仅监听本机的 Node 代理；代理用官方腾讯云 OCR SDK 调用 `LicensePlateOCR`，返回首选车牌、全部候选、颜色、置信度、坐标及 RequestId。接口返回示例：

```json
{
  "plateNo": "京A12345",
  "confidence": 0.98,
  "candidates": [{ "plateNo": "京A12345", "confidence": 0.98, "color": "蓝", "rect": { "x": 20, "y": 30, "width": 120, "height": 38 } }],
  "requestId": "腾讯云请求编号"
}
```

代理只接收最多 4 MB 的 JPG/PNG；缺少密钥、图片无车牌、额度不足等错误会显示在页面中。腾讯云官方 [车牌识别接口文档](https://cloud.tencent.com/document/api/866/36211)说明图片经 Base64 编码后上限 10 MB，`Confidence` 为 0–100，且可能返回多个 `LicensePlateInfos`。本系统将置信度转为 0–1，值守员仍需人工核对。当前没有接入真实数据库、支付或道闸；后续应由后端提供幂等写入、报价、支付核验及设备回执接口。

## FTP 车牌收件（可选）

外部程序可在视频中检测车牌、裁剪车牌图片后，通过 FTP 上传到收件目录；本地代理每 3 秒轮询该目录，自动调用腾讯云识别，结果显示在“出入口值守”页面的“FTP 车牌接收”卡片中，值守员核对后点击“填入入场 / 填入出场”，再按现有流程确认。相比整帧上传，只识别裁剪后的车牌可显著减少腾讯云调用量。

在根目录 `.env` 填写以下变量（保存后 `npm run dev` 会自动重启代理，终端会显示“FTP 轮询：已配置 / 未配置”）：

```dotenv
FTP_HOST=            # 例如 192.168.1.10
FTP_PORT=21
FTP_USER=
FTP_PASSWORD=
FTP_INBOX_DIR=       # 例如 /plates/inbox
```

上传约定：JPG 或 PNG、单张不超过 4 MB、文件名不重复（建议含时间戳）。代理会跳过最近 2 秒内出现、或连续两轮大小不一致（可能仍在写入）的文件。识别成功的文件会移动到收件目录下的 `processed/`（重命名为 `日期时间_原文件名`），失败或无法识别的文件移动到 `failed/`；未配置腾讯云密钥时文件会保留在收件目录中，配置后自动补处理。未配置 FTP 时页面卡片会提示配置方法，不会报错。

无需外部程序即可手工验证（请在仓库根目录运行）：

```bash
node server/scripts/ftp-send-test.mjs "车牌照片（京Q01US9）.jpg"
```

上传后约 6 秒内页面卡片会出现识别结果；测试完成后可在 FTP 服务器上确认文件已移动到 `processed/`。
